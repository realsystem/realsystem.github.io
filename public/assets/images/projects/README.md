# Project Images Directory

Place all project images here.

## Naming Convention

Use descriptive names that match your project slug:

```
lift-kit-installation-hero.jpg
lift-kit-installation-parts.jpg
lift-kit-installation-install.jpg
lift-kit-installation-results.jpg
```

## Image Guidelines

- **Hero images:** 1920x1080px or 1280x720px (16:9 ratio)
- **Content images:** 1200-1920px wide
- **Format:** JPG for photos, PNG for screenshots
- **Size:** Optimize for web (< 500KB per image ideal)

## Organization

You can organize by project if you have many images:

```
projects/
├── lift-kit/
│   ├── hero.jpg
│   ├── parts.jpg
│   └── install.jpg
└── roof-rack/
    ├── hero.jpg
    └── build.jpg
```

Then reference as: `/assets/images/projects/lift-kit/hero.jpg`
